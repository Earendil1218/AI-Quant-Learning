### 1. `DataFrame.tail()`

`history` 是一个 pandas `DataFrame`。

```python
history.tail()
```

用于查看 DataFrame 最后几行数据。

不传参数时，默认返回最后 5 行：

```python
history.tail()
```

指定数字后，可以控制返回的行数：

```python
history.tail(10)
```

表示返回最后 10 行数据。

### 4. IBKR 历史数据的处理流程

核心流程可以理解为：

```text
IBKR / TWS
    ↓
ib.reqHistoricalData()
    ↓
bars
    ↓
util.df(bars)
    ↓
history（DataFrame）
    ↓
return history
```

第一步：

```python
bars = ib.reqHistoricalData(...)
```

通过 `ib` 对象调用 `reqHistoricalData()`，从 IBKR 获取历史行情数据。

第二步：

```python
history = util.df(bars)
```

使用 `ib_insync` 的 `util.df()` 将返回的数据转换为 pandas DataFrame。

第三步：

```python
return history
```

将处理完成的 DataFrame 返回给调用这个函数的代码。
