# AI Quant Learning

AI Quant Lab 学习记录仓库。

本仓库用于记录 AI Quant Lab 建设过程中涉及的学习内容，与正式项目代码仓库独立维护。

## Learning Topics

主要学习内容包括：

- Python
- pandas
- IBKR / TWS / API
- 期权
- 量化交易
- 软件工程

## Daily Learning Logs

每天的学习过程记录在 `daily/` 目录中，按照年份和月份管理：

daily/
└── 2026/
    └── 08/
        └── 2026-08-12.md

学习日志主要记录：

- 当天学习的内容
- 新理解的知识
- 重要代码和概念
- 学习过程中发现的问题
- 当前学习进度
- 下一阶段学习计划

## Repository Structure

本仓库只保存学习记录和知识总结。

AI Quant Lab 的正式项目代码在独立仓库中维护，不在本仓库复制或修改正式项目代码。
